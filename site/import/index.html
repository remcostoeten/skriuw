The import path

A migration should explain itself before it changes the archive.

Import is a preview-plan-apply operation. Cancelling during intake, preview, or image transfer leaves the workspace unchanged.

01 / Select

Choose the local export

Use a folder, individual files, ZIP, provider backup, or JSON export. Skriuw detects the likely format without uploading it.

02 / Inspect

Read the plan

Review counts, destination, detected format, re-import behavior, and every fidelity or safety warning.

03 / Apply

Commit once

Confirmed notes, folders, tags, properties, images, and import receipts enter the workspace as one atomic operation.

Supported sources

Use the export your current app already gives you.

Skriuw reads documented export formats and ordinary local files. It does not log in to another notes service or read a private application database.

Obsidian

Vault folder

Preserves the folder tree, supported frontmatter, unambiguous local image embeds, and wikilinks with a unique target. Alias and heading links stay exact source when conversion would lose meaning.

Notion

Markdown & CSV ZIP

Imports the downloaded ZIP directly, removes page UUID suffixes, turns database rows into notes, and maps CSV columns to typed properties.

Bear

.bear2bk / TextBundle

Reads Markdown, images, timestamps, and exported tags. Encrypted and trashed notes stay skipped and appear in the completion report.

Apple Notes

Markdown files

Uses Apple's official selected-note Markdown export. Collect the exported files in a folder; Skriuw does not access Apple's private Notes database.

Evernote

ENEX

Imports notebooks, checkboxes, code blocks, tables, and formatting. Encrypted content and embedded attachments become visible placeholders in the report.

Joplin

RAW export folder

Turns notebooks into nested folders and resolves links to exported resources. Use Joplin's RAW export rather than JEX.

Simplenote

notes.json

Imports active notes, tags, timestamps, and pins. Trashed notes remain skipped and counted.

Plain files

Markdown / text / ZIP

Bring ordinary files and folders without naming a provider. Skriuw also recognizes Google Keep Takeout, Standard Notes backups, and several structured export formats.

Fidelity over guesses

Ambiguous content remains visible, portable source.

Links

Only unique targets resolve automatically. Ambiguous wikilinks and image names remain source text instead of pointing to a guessed note or file.

Unsupported syntax

Markdown that the structured editor cannot represent safely stays intact in raw mode. The import report tells you what was preserved.

Remote content

Remote images remain blocked. Local images transfer through a bounded, cancellable path and are verified before the import commits.

Re-import

Durable receipts let a later import skip previous matches, update imported content, or create deliberate copies.

Archives reject absolute paths, parent traversal, symlinks, duplicate case-insensitive paths, excessive depth, excessive entry counts, and expanded data beyond bounded safety limits.

Your old archive should arrive with a receipt, not a leap of faith.
