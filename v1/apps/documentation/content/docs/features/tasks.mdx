---
title: "Tasks"
description: "Turn action items into workspace tasks, then work with the same task list as a list, board, editable table, or calendar."
---

Tasks give actionable work a home outside any single note. A task can stand on its own or stay linked to the note and block it came from, so you can plan across your workspace without losing the original context.

Tasks are available in signed-in workspaces and local desktop vaults. In a guest
workspace, the Tasks route explains what is needed instead of presenting a blank
or broken page.

## Create a task

You can create tasks in three ways:

- **From the Tasks workspace** - type a title into the quick-add field and press Enter
- **From a checklist item** - hover over the item and choose **Convert to task**
- **From selected note text** - select the text and choose **Create task from selection**

Tasks created from a note carry a violet **From a note** marker. Open the task details and choose **Open source note** to return to the original context.

## Choose a view

Every view uses the same tasks. An edit made in one view is reflected in the others.

- **List** - groups tasks into Overdue, Today, Scheduled, Inbox, and Completed, making it useful for deciding what to do next
- **Board** - shows To do, In progress, and Done as status columns for a quick progress overview. Change a card's status in its details or in Table view
- **Table** - shows tasks in a compact grid. Edit status, priority, and due date directly in the table, or select a title to open the full details
- **Calendar** - places tasks on their due dates. Move between months, select a task to inspect it, or select a day to open a date-filtered List view. Dots also show days that contain journal entries

## Edit task details

Task titles and descriptions save when you leave the field; press Enter to commit
a title immediately. Updates are serialized, so quick edits do not overwrite one
another. From task details you can update:

- Title and description
- Status and priority
- Due date
- Tags and assignees
- The source note, when the task was created from note content

You can also mark a task complete from the list. Deleting a task requires a
confirmation because it permanently removes the task.

## Filter your work

Use **Hide completed** when you want to focus on active work, then switch it off
when you need the full history. Selecting a day in Calendar view applies a local
date-safe filter and moves you to List view; clear the date chip to return to all
tasks. Future tasks are collected under **Scheduled**, so they do not disappear
from a day-to-day review.

## Tips

- Use List view for a daily review and Calendar view for deadline planning
- Use Table view when several tasks need status, priority, or due-date changes
- Convert checklist items when an action starts inside a note but needs to be tracked across the workspace
- Add a due date only when the date is meaningful; undated tasks remain easy to find in Inbox

## Why use Tasks?

Notes preserve thinking and context; Tasks keep the actions moving. Linking the two means a project can be planned across views while each task still points back to the decision, meeting, or idea that created it.
