---
title: "Marks, Threads, and Readings"
description: "Turn important prose into editable semantic Marks, group it into Threads, and keep source-linked Readings current inside a note."
---

Marks turn a useful fragment of prose into information you can revisit without
pulling it out of its original sentence. A **Thread** groups related Marks; a
note's **Readings** inspector then summarizes the thread while keeping every
source one click away.

## Create a Mark

In the block editor, select text and choose **Mark selection** from the floating
toolbar. Choose a meaning, color, optional Thread, and optional note, then choose
**Create Mark**.

Skriuw suggests a meaning from the selected text. The available meanings are:

- Amount
- Count
- Moment
- State
- Person
- Place
- Reference

You can use any of six colors. Automatic detection is off by default, so regular
prose is never silently turned into an atomic Mark. Turn it on in Editor settings
only if you want Skriuw to recognize amounts, dates, counts, states, and links as
you type.

## Edit or remove a Mark

Select a Mark in the editor to open its editor. You can change its visible text,
meaning, color, Thread, and note. Choose **Convert to text** to remove the Mark
while keeping the words in place.

This is useful when a date, amount, or status changes: update the source once and
the Reading changes with it.

## Group information with Threads

Give related Marks the same Thread name, such as `Accommodation`, `Launch`, or
`Research budget`. Threads are local to the note and preserve the exact name you
entered. Marks without a Thread stay visible under **Unthreaded** rather than
disappearing.

## Readings inspector

Open the note inspector to find **Readings**. It is visible even before the first
Mark, with a short prompt explaining how to begin.

For every Thread, Readings shows:

- Number of source Marks
- Amount totals, separated by currency
- Count totals
- Current state values
- Every source Mark

Choose a source to scroll to and focus the original Mark in the editor. This makes
Readings a live view, not a separate copy that can become stale.

## Portability

Marks round-trip through Skriuw Markdown export/import, including their meaning,
color, note, and Thread. Skriuw also preserves this metadata when copying rich
HTML. Markdown remains readable when opened outside Skriuw.

## Marks and tasks

Use Marks for facts, decisions, dates, and evidence. Use [Tasks](/features/tasks)
for actions that need to move across a workspace. Both can start from selected
note text, but a Task tracks work while a Mark keeps information connected to its
source.
