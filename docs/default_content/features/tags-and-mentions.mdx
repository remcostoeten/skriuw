# Tags and mentions

Skiruw lets you organize and connect your notes without leaving the page. Type a trigger character and a menu pops up right where you're writing.

## How it works

- Type **#** followed by a word to add a **tag** — e.g. `#project`
- Type **@** followed by a name to **mention a note** and link to it
- Type **$** followed by a name to **mention a person**

Each trigger opens a small menu so you can pick an existing match or create a new one on the spot.

## Tags

- Tags collect automatically into a **Tags** overview page
- From there you can **rename, recolor, merge, or delete** a tag
- Renaming or merging a tag updates every note that uses it — you never have to hunt down old references

## Note mentions

Typing **@** and picking a note drops in a link to it. If no matching note exists yet, you can create one straight from the menu, right as you type.

## Person mentions

- Typing **$** and a name mentions a person across your notes
- Everyone you've mentioned collects into a **People** page
- Renaming a person updates every mention of them instantly, everywhere

## Tips

- You don't need to set anything up first — tags and people are created the moment you type them
- Use tags for topics and themes, and person mentions for the people your notes are actually about
- The overview pages are a fast way to see everything connected to a tag or person in one place

## Why use tags and mentions?

Notes are only useful if you can find them again. Tags and mentions turn plain text into a web of connections you build just by writing naturally — no extra clicks, no separate database to maintain, and renaming something never leaves broken references behind.
