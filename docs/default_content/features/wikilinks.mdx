# Wikilinks

Skiruw lets you link notes together with **wikilinks** — type `[[note title]]` (or use the `@` menu) to connect ideas without leaving your writing flow.

## How it works

Type `@` in the editor to open a menu of your existing notes. Pick one to insert a link, or choose **Create new note and link** to link to a note that doesn't exist yet. You can also type a link directly as `[[Note Title]]` and Skiruw turns it into a clickable link chip.

## What you can do

- **Link between notes** — connect related ideas, projects, or references with a single link
- **Jump instantly** — click a link chip to open the linked note right away
- **Create on the fly** — link to a title that doesn't exist yet, and clicking it creates a new note with that title
- **See backlinks** — open a note's info panel to see every other note that links back to it

## Tips

- Keep note titles unique. If more than one note shares the same title, a link to that title opens the first matching note instead of asking which one you meant.
- Links point to the note's title text, not a fixed connection — so if you rename a note, links that used its old title will no longer find it and will offer to create a new note instead. Update important links after a rename.
- Check the backlinks section in a note's info panel to see what else in your workspace references it.

## Why use wikilinks?

Notes are more useful connected than isolated. Wikilinks let you build a web of related ideas — project notes linking to reference material, journal entries linking to people or topics — so you can navigate by association instead of hunting through folders.
