# Writing

Everything here is something you can type. No menus required, though there's a `/` menu when you want one.

## The basics, by typing

Wrap a word in `**stars**` for **bold**, `*one star*` for *italic*, `~~tildes~~` for ~~struck through~~, and backticks for `inline code`. The characters disappear as soon as the mark applies.

Start a line with `#` and a space for a heading. More hashes, smaller heading, down to six.

Start a line with `-` for a bullet, `1.` for a number, `>` for a quote, or three dashes for a divider.

## Code, with the colours on

Fence a block with three backticks and name the language:

```typescript
function greet(name: string): string {
  return `Hello, ${name}`;
}
```

```bash
rg "todo" --type md
```

Bash, CSS, diff, Go, JavaScript, JSON, Markdown, Python, Rust, SQL, TypeScript, XML and YAML all get highlighted. Anything else stays plain, which is fine too.

## Moving things around

Hover the left edge of any block and a handle appears. Drag it anywhere. Paragraphs, lists, tables, code — all of it moves as one piece.
