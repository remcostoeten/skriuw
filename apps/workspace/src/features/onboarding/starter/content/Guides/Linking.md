# Linking

Folders decide where a note is stored. Links connect it to the other notes and topics it relates to.

## Three shortcuts

Type `@` and start typing a title to link to another note, like [[Welcome]] or the example in [[Launch checklist]]. Choose "Create" to make a new note and link it in one step. The link stays valid if you rename the note later.

Type `#` for a tag, then a word, such as `guide`, `reference` or `someday`. A tag is a word you can search for later, so use a few and reuse them.

Type `$` for a person, then a name. This helps once more than one person appears in your notes.

## Why link notes

A note can be in only one folder. A link can connect it to every topic it belongs to.

- A meeting note tagged for the project, mentioning the person who owns it
- A reading note linking to [[Reading list]] and the idea it changed
- An idea linking back to the note that caused it

None of these depend on which folder the note is in.

## Backlinks

Open any note to see which notes link to it. You can find a note you forgot about this way, because another note mentions it.

## A suggested order

1. **Capture** the note without choosing a folder or tags.
2. **Link** it to the closest related note you already have.
3. **Tag** it only if you would search for that word.
4. **File** it later, or not at all. Search does not depend on folders.

## Finding things again

`Cmd/Ctrl + K` opens the command palette, which searches notes, actions and settings. `Cmd/Ctrl + /` lists every shortcut, including the ones you've rebound.
