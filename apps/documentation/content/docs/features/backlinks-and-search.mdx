Skiruw keeps track of which notes point to each other, and lets you search with simple filters instead of scrolling through everything.

## How it works

Whenever you link to a note using `[[Note Title]]`, Skiruw remembers that connection. Open the linked note and you'll see a **Backlinks** section listing every note that references it — automatically, with nothing extra to set up.

## Capabilities

- **Automatic backlinks** — no manual linking back required; if Note A links to Note B, Note B shows Note A as a backlink
- **One entry per note** — even if a note links to another multiple times, it only shows up once in the list
- **Jump straight there** — click a backlink to open the source note immediately
- **Outgoing links too** — the same panel shows notes you link out to, not just notes linking in
- **Tag search** — type `tag:` or `#` followed by a tag name (e.g. `tag:recipes` or `#recipes`) to filter to notes with that tag
- **Person search** — type `person:` or `$` followed by a name (e.g. `person:ann` or `$ann`) to filter to notes mentioning that person
- **Combine with text** — mix filters and plain words in one search, like `#recipes pasta`, and results match all of them
- **Stack filters** — use more than one filter at once, like `#recipes person:ann`, to narrow down further

## Tips

- Backlinks update as you edit — remove a link and the backlink disappears too
- Tag and person filters are case-insensitive, so `#Recipes` and `#recipes` behave the same
- Free text still searches note content, so filters and keywords work together, not instead of each other

## Why use backlinks & search operators?

Backlinks reveal the web of connections between your notes without any extra bookkeeping — you just link naturally and Skiruw tracks the rest. Search operators turn a flat list of notes into something you can slice by topic or person in seconds, so finding the right note is a quick filter away instead of a manual hunt.
