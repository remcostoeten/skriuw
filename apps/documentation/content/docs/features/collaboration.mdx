Skiruw lets you invite others to work on a note with you, live — everyone's changes appear in the same document as they type.

## How it works

Share a note with someone (or let them request access) and, once they're added as a collaborator, the note becomes a live space. Open it at the same time and you'll both see each other's edits appear as they happen, in the same editor.

## Getting people in

- Share a note and set each collaborator as a **viewer** (read-only) or **editor** (can make changes)
- People can also **request to collaborate** on a note; the owner sees the request and can accept or decline it
- The owner manages who's on a note and can change someone's permission or remove their access at any time

## While you're working together

- A small avatar stack appears when others are on the same note, showing who's currently here
- Open it to see everyone's name, their role, and whether they're actively typing, active, or idle
- A "Live" indicator lets you know the note is currently shared with someone else, switching to "Typing" when a collaborator is mid-edit
- A short recent-edits feed shows who made changes and when

## Tips

- Only notes that have been shared show any of this — a private note behaves exactly as before
- Set collaborators to viewer if you want them to follow along without being able to change anything
- Revoke access any time from the collaborators list if you want to close a note back off

## Why collaborate?

Some notes are better written together — planning docs, shared journals, project notes. Instead of passing a file back and forth or losing track of who changed what, everyone works in the same note at once, and you can always see who else is there.
