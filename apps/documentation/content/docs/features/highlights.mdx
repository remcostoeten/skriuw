---
title: "Highlights and tasks"
description: "Highlight important text, label it, and turn selected prose into source-linked tasks."
---

Highlights keep important words visible without moving them out of their
sentence. Select text in the block editor, then choose the **highlighter** in
the floating toolbar.

## Highlight text

Choose one of four colors: yellow, green, blue, or pink. Add an optional short
label such as `Decision`, `Deadline`, or `Evidence`, then choose **Highlight**.

- Highlighted text remains normal, editable prose.
- Hover a highlight to read its label and inferred kind.
- Skriuw recognizes common values such as amounts, dates, counts, and states.
- Highlight color and label are stored with the text and survive Skriuw
  Markdown export and import.

## Create task from selected text

Select an action in a note, then choose the **task** icon beside highlighter.
Skriuw creates a workspace task using selected text as task title.

The task stores its source note and source block. This preserves traceability:
the task list can identify where work came from while note remains original
context.

This action needs task-capable workspace. It is unavailable in guest mode.

## Highlights, comments, and ink

- **Highlights** identify meaningful text and can carry color and label.
- **Comments** start discussion on selected text in shared notes.
- **Annotate mode** adds freehand ink over whole note. See [Note annotations](/features/annotations).
